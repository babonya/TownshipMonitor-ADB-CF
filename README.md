# TownshipMonitor-ADB (Cloudflare 판)

꿈의마을(Township) 헬리콥터 주문 자동 거래봇입니다. 원작자의 **TownshipMonitor-ADB**(실폰 ADB 판)에 무인 운영용 기능을 추가했습니다.
원작자의 허락을 받아 편집·배포합니다. 원작자 설명서는 [readme.txt](readme.txt)에 그대로 있습니다.

> 목표: **켜 두면 사람 손 없이 계속 거래가 진행되는 것.** 멈추는 경우를 하나씩 찾아서 자동으로 넘기도록 고쳐 왔습니다.

---

## 1. 준비물

| 항목 | 내용 |
|---|---|
| PC | Windows 10/11 64비트, 인터넷 연결 (GPU 필요 없음) |
| 폰 | 안드로이드, USB 디버깅 켜기, 데이터용 USB 케이블 |
| 해상도 | 가로 기준 **1600×720(HD+)** 또는 1544×720만 지원 |
| 게임 | Township 설치, 게임 언어 **English** |
| AI | Cloudflare 무료 계정 (상품 비교용, 하루 10,000 뉴런 무료) |
| 알림(선택) | 텔레그램 봇 |

### 폰 설정 (갤럭시 기준) — 꼭 하세요
1. **해상도**: 설정 → 디스플레이 → **화면 해상도** → 세로로 들었을 때 **가로폭이 720인 가장 낮은 해상도(HD+, 720×1600)** 선택.
   이 프로그램의 인식 이미지는 폭 720에 맞춰져 있습니다. 개발자 옵션의 "최소 너비"나 `wm size`로 억지로 맞추지 마세요.
2. **게임 부스터 화면 잠금 끄기**: 게임 중 게임 부스터 아이콘(또는 Game Launcher → 게임 부스터) → **터치 잠금/화면 잠금 자동 실행 끄기**.
   켜져 있으면 일정 시간 뒤 화면이 어두워지며 잠겨서 봇이 화면을 못 읽고 **중간에 멈춥니다**.
3. **개발자 옵션**: 설정 → 휴대전화 정보 → 소프트웨어 정보 → 빌드번호 7번 탭 → 개발자 옵션에서 **USB 디버깅** 켜기, **화면 켜짐 상태 유지** 켜기.
4. 게임 언어 **English**, 폰은 가로로 게임 화면이 떠 있게 둡니다.

> 원작자 폰처럼 1544×720인 기기도 원작자 프로필로 인식됩니다. 다만 우리가 추가한 팝업 규칙·카메라 자동 복원은 1600×720 실기기에서만 검증했습니다(1544에선 팝업 규칙은 배율 보정으로 시도, 카메라 복원은 건너뜀).

Node.js 24, Python 3.12, .NET 8 Desktop Runtime, adb(platform-tools)는 **처음설정이 확인하고 설치를 안내**합니다.

## 2. 설치

1. [Releases](../../releases)에서 `TownshipMonitor-ADB-CF-<날짜>.zip`을 받아 **`C:\TownshipMonitor-ADB`** 에 풉니다. (C 드라이브 바로 아래에 두세요. 바탕화면·다운로드·OneDrive 폴더는 경로 문제로 안 됩니다.)
2. 폰을 USB로 연결하고, 폰에 뜨는 "USB 디버깅 허용"에서 **항상 허용**을 누릅니다.
3. 폰에서 게임을 켜 두고 마을 화면을 띄워 둡니다.
4. **`처음설정.cmd`** 를 더블클릭합니다. 단계마다 Y/N으로 물어보니 안내를 따라가면 됩니다.
   - 필요한 프로그램 확인·설치(winget)
   - 이미지 인식 환경(`.venv-perception`) 만들기
   - Cloudflare Account ID·API 토큰 입력(토큰은 화면에 안 보임) → 토큰 확인
   - (선택) 텔레그램 봇 토큰 입력 → chat id를 자동으로 찾고 시험 메시지 전송
   - 폰 연결·해상도·게임 설치 확인 → 기기 정보(`setup-local\device.json`)와 세션 만들기
5. **`점검.cmd`** 로 모든 항목이 `[통과]`인지 확인합니다. 아무것도 바꾸지 않고 검사만 하니 언제 돌려도 안전합니다.

### Cloudflare 키 발급
1. https://dash.cloudflare.com 가입 → 오른쪽(또는 계정 홈)에서 **Account ID** 복사
2. My Profile → **API Tokens** → Create Token → **Workers AI** 템플릿(또는 권한 Workers AI: Read/Edit) → 토큰 복사
3. 처음설정에서 붙여넣기

### 텔레그램 봇 만들기(선택)
1. 텔레그램에서 파란 체크가 있는 **@BotFather** 검색 → `/newbot` → 이름·아이디(`..._bot`) 정하기 → 토큰 받기
2. 만든 **내 봇**에게 아무 메시지나 한 번 보내기
3. 처음설정에서 토큰을 넣으면 chat id를 찾아 줍니다.

### 비밀값은 어디에?
Cloudflare·텔레그램 값은 이 PC의 **Windows 사용자 환경변수**에만 저장됩니다
(`CLOUDFLARE_ACCOUNT_ID`, `CLOUDFLARE_AUTH_TOKEN`, `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID`).
배포 파일에는 들어 있지 않고, 릴리즈를 만들 때 실제 값이 섞였는지 자동 검사합니다. 남에게 보여 주지 마세요.

## 3. 실행

1. **`시작.cmd`** 더블클릭 → 간단 점검 후 AI 중계기·감시·모니터 창이 함께 뜹니다.
2. 모니터 창에서 **`시작`** 을 누릅니다. (새 세션은 일시정지 상태라 창만 열면 아무것도 안 합니다.)
3. 처음 한두 시간은 지켜보세요. 결제·구매 안내 창은 절대 누르지 않고 닫기(X)만 누릅니다.

- 멈추기: 모니터 `일시중지`. 감시는 사람이 일시정지한 것은 건드리지 않습니다.
- 폰을 직접 만지며 플레이할 때도 먼저 `일시중지`를 누르세요.
- 폰 설정 권장: 개발자 옵션 **화면 켜짐 상태 유지**, 삼성 게임 부스터의 **터치 잠금 끄기**.

## 4. 원작자 판과 다른 점

| 기능 | 설명 |
|---|---|
| Cloudflare AI 중계기 | 원작자의 로컬 AI(D1, GPU 필요) 대신 Cloudflare Workers AI로 상품을 비교합니다. 같은 주소(8087)를 흉내 내서 봇 코드는 그대로입니다. |
| AI 절약 | 확연히 다른 쌍은 PC에서 먼저 거름(약 90%), 같은/비슷한 쌍은 저장된 답을 재사용(캐시 적중 60~75%). 배포본에 **약 9,900쌍의 답 씨앗**이 들어 있어 처음부터 호출이 줄어듭니다. |
| 시작 후 자동 위치 맞추기 | 게임이 꺼져 있으면 자동 실행, 마을 카메라가 틀어지면 줌아웃 → 창고·시장을 찾아 기준 배율로 되돌립니다. |
| 감시(자동 재시작) | 6분 동안 입력이 없거나 같은 동작만 반복(헛돌기)하면 모니터의 `프로그램 재시작` → `시작`을 대신 누릅니다. |
| 텔레그램 알림 | 멈춤 감지 시 **폰 화면 캡처 + 상태 코드 설명**을 보냅니다. 복구 실패·복구됨·1시간 납품 0·프로그램 꺼짐도 알립니다. |
| 팝업 처리 | 레벨업, Town Cards, 친구 카드(CARD RECEIVED), Mayor's Cup CONTINUE, Piggy Bank, Treasure Hunt, 끝난 이벤트 QUIT, 이벤트 화면 X, 튜토리얼 화살표 |
| 미니게임 주문 | 멈추지 않고 그 주문을 건너뛰고 다른 주문을 처리 |
| 속도 | 폰 PNG 대신 raw 캡처(캡처 약 1초 → 0.6초, 시장 스크롤 결과 약 7초 → 3초) |
| 1600×720 지원 | 원작자 1544×720 프로필을 바탕으로 1600×720 프로필 추가 |
| 처음설정·점검 | 설치·설정 안내와 점검 배치 파일 |

### 알아 두실 것 — 이벤트는 포기합니다
**Flip the Tiles 같은 이벤트·미니게임 화면에 들어가 멈추면, 봇은 그 이벤트를 그냥 넘기고 닫아 버립니다**
(끝난 이벤트의 "Quit?" 확인창은 QUIT, 그 외엔 X). 이벤트 보상(쇼 스타 등)을 잃을 수 있습니다.
이벤트보다 **헬리콥터 주문을 끊김 없이 계속 처리하는 것이 더 중요**하다고 보고 이렇게 정했습니다.

## 5. 멈춤 사례와 자동 처리

| 멈춤 / 상태 코드 | 처리 |
|---|---|
| `PROCESS_TIMEOUT` (시장 스크롤 adb 시간초과) | 감시 자동 재시작 |
| `SOM_HTTP_502` (AI 중계 오류, 모니터가 스스로 일시정지) | 자동 재시작 |
| `SOM_SCREEN_UNIDENTIFIED` (모르는 화면·팝업) | 아는 팝업은 규칙으로 닫기, 모르는 화면은 캡처 저장 + 텔레그램 |
| `SOM_ORDER_REOBSERVE` 대기 | 보통 1분 안에 자체 해소 |
| 시장·창고만 무한 반복(헛돌기) | 헛돌기 감지 → 재시작 |
| `ADB_TARGET_NOT_FOREGROUND` (게임 꺼짐) | 홈 화면이면 게임 자동 실행 |
| 마을 카메라 틀어짐 | 핀치 줌으로 자동 복원 |
| 레벨업·이벤트 안내·튜토리얼 | 팝업 규칙(밝은 부분 누르기, X, CONTINUE, QUIT) |
| 이벤트 Quit 확인창 무한 반복 | 끝난 이벤트는 QUIT |

### 아직 사람이 필요한 것
- 처음 보는 새 이벤트 안내 창, DAILY REWARDS(출석 보상) 등 등록 안 된 화면
- 이런 화면에서 멈추면 감시가 텔레그램으로 캡처를 보내니, 폰에서 직접 해결한 뒤 다시 `시작`하세요.

## 6. 자주 막히는 곳
- **폰이 안 보임 / unauthorized**: USB 디버깅, 데이터 케이블, "항상 허용", USB 모드 파일 전송. 이 프로그램의 adb는 포트 **15037**을 씁니다.
- **해상도 [필요]**: 디스플레이 → 화면 해상도 → HD+. 바꾼 뒤 `setup-local\device.json` 삭제 → 처음설정 다시.
- **429 / 한도**: Cloudflare 무료 하루 10,000 뉴런, 한국 시간 오전 9시 초기화.
- **401/403**: 토큰 권한(Workers AI) 또는 복사 오류 → 처음설정 다시.

## 7. 앞으로
- **원격 켜기/끄기**: 테일스케일(Tailscale)로 폰에서 접속하는 모바일 페이지를 만들어, 밖에서도 봇·게임을 끄고 켤 수 있게 할 예정입니다.
- DAILY REWARDS 등 새 날 팝업 추가 등록.
