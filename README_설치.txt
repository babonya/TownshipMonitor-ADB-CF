꿈의마을(Township) 자동 거래봇 - 설치 안내
==========================================

이게 뭔가요
-----------
원작자가 만든 Township 자동 거래 프로그램(TownshipMonitor-ADB)에 아래를 추가한 판입니다.
 - Cloudflare AI 중계기: 상품 비교를 클라우드(무료 한도)로 처리해서 PC에 GPU가 없어도 됩니다.
 - 감시: 봇이 멈추면 자동으로 다시 시작하고, 텔레그램으로 알려줍니다 (선택).
 - 팝업 처리: 레벨업, 이벤트 안내 등 모르는 창을 닫는 규칙.
원작자의 설명서는 readme.txt 에 그대로 있습니다. 원작자 프로그램의 크레딧과 저작권은 원작자에게 있습니다.

준비물
------
 - Windows 10/11 64비트 PC (인터넷 연결)
 - 안드로이드 폰 + 데이터 전송 가능한 USB 케이블, 폰의 "USB 디버깅" 켜기
     (설정 -> 휴대전화 정보 -> 소프트웨어 정보 -> 빌드번호 7번 탭 -> 개발자 옵션 -> USB 디버깅)
 - 폰 화면 해상도 HD+ : 가로 화면 기준 1600x720 (또는 1544x720)만 지원합니다.
     (갤럭시: 설정 -> 디스플레이 -> 화면 해상도 -> 가로폭 720인 가장 낮은 해상도 HD+ 선택. 인식이 폭 720에 맞춰져 있음)
 - 삼성 게임 부스터의 터치 잠금(화면 잠금) 끄기 — 켜져 있으면 화면이 잠겨 중간에 멈춥니다.
 - Township 게임 설치, 게임 언어 English
 - Cloudflare 무료 계정 (처음설정 중에 안내합니다)

사용 순서
---------
0) 압축을 C:\TownshipMonitor-ADB 에 풉니다 (C 드라이브 바로 아래. 바탕화면·다운로드·OneDrive 폴더는 안 됩니다).
1) 처음설정.cmd 더블클릭
   - 화면의 안내를 따라가면 됩니다. 설치/입력 전에는 항상 Y/N으로 물어봅니다.
   - 필요한 프로그램(Node.js 24, Python 3.12, .NET 8, adb), 이미지 인식 환경,
     Cloudflare 키, (선택) 텔레그램, 폰 연결, 세션 만들기까지 한 번에 확인합니다.
   - 설치 도중 "이 창을 닫고 다시 실행하세요"라고 나오면 그렇게 하세요 (설치된 프로그램을 새로 인식시키기 위함).
   - 게임은 미리 폰에서 실행해 가로 게임 화면(마을)이 떠 있는 상태로 두세요.
2) 점검.cmd 더블클릭
   - 모든 항목이 [통과]이면 준비 끝입니다. [필요]는 반드시 해결, [경고]는 읽어보고 넘어가도 됩니다.
   - 아무것도 설치하거나 바꾸지 않고 검사만 합니다. 언제든 다시 돌려도 안전합니다.
3) 시작.cmd 더블클릭
   - 간단 점검 후 모니터 창이 열립니다. 모니터 창에서 "시작"(Start) 버튼을 누르면 봇이 일합니다.
   - 새로 만든 세션은 일시정지 상태라 창만 열어서는 아무것도 하지 않습니다.
   - 처음에는 직접 지켜보세요. 이상한 창(결제/구매 안내)이 뜨면 봇은 닫기(X)만 누르도록 되어 있습니다.

텔레그램 알림 (선택)
-------------------
처음설정에서 "텔레그램 설정?"에 N을 하면 건너뜁니다. 하려면:
 1. 텔레그램에서 @BotFather -> /newbot -> 토큰을 받습니다.
 2. 만든 내 봇에게 아무 메시지나 하나 보냅니다.
 3. 처음설정이 토큰으로 내 chat id를 찾아서 보여줍니다. 맞다고 확인하면 저장하고 시험 메시지를 보냅니다.

비밀값은 어디에 저장되나요
-------------------------
Cloudflare Account ID / API 토큰, 텔레그램 봇 토큰 / chat id는 이 PC의 "사용자 환경변수"에만
저장됩니다 (CLOUDFLARE_ACCOUNT_ID, CLOUDFLARE_AUTH_TOKEN, TELEGRAM_BOT_TOKEN, TELEGRAM_CHAT_ID).
배포 파일과 폴더 안의 어떤 파일에도 쓰이지 않습니다. 이 값들을 남에게 보내거나 화면 공유하지 마세요.
지우려면: Windows 검색 "환경 변수 편집" -> 사용자 변수에서 삭제 (토큰은 Cloudflare 사이트에서 폐기도 가능).

자주 막히는 곳
-------------
 - "폰이 안 보임 / unauthorized": 폰 USB 디버깅 켜기, 케이블을 데이터용으로 교체, 폰 화면에 뜬
   "USB 디버깅을 허용하시겠습니까?"에서 "항상 허용". USB 모드를 "파일 전송"으로. 다시 점검.cmd.
   (이 프로그램의 adb는 고정 포트 15037을 씁니다. 다른 adb를 쓰는 프로그램(Nox·MuMu 같은 에뮬레이터 도구)과 충돌하면 그쪽을 잠시 끄고 하세요.)
 - 해상도 [필요]: 폰 화면 해상도를 HD+로 바꾸세요. 개발자 옵션의 "최소 너비"로 맞추지 마세요.
   바꾼 뒤에는 setup-local\device.json 을 지우고 처음설정.cmd를 다시 실행합니다.
 - 폰을 바꾸거나 폰을 재부팅한 뒤 [경고] 또는 동작 이상: readme.txt 8절(재바인딩)을 참고하세요.
 - 429 오류 / "한도": Cloudflare 무료는 하루 10,000 뉴런까지입니다. 한국 시간 오전 9시에 초기화됩니다.
   그때까지 기다리거나 Cloudflare 유료 플랜을 쓰세요.
 - 401/403 오류: 토큰에 Workers AI 권한이 없거나 잘못 복사했습니다. 처음설정.cmd로 다시 입력하세요.
 - 게임 글자 인식이 이상함: 게임 언어가 English인지, 폰 화면이 꺼지지 않게
   (개발자 옵션 "화면 켜짐 상태 유지") 되어 있는지 확인하세요.

더 자세한 원작자 설명은 readme.txt 를 보세요.
