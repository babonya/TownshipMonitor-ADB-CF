Township Monitor — Android ADB 버전

Windows PC에 연결한 Android 기기의 Township 화면을 읽고 반복 작업을 자동으로
수행하는 프로그램입니다. 현재 헬리콥터 주문 확인·배송, 필요한 상품의 시장 구매,
조건에 따른 주문 삭제와 창고 공간 확보를 지원합니다. 화면 인식과 상품 이미지 비교는
PC의 로컬 AI 모델로 처리하며, 실행·일시정지와 진행 상황을 모니터 창에서 관리합니다.
시장에서 상품을 4회 구매하면 주문 화면으로 돌아가 배송 가능 여부를 다시 확인합니다.
미니게임은 사용자가 직접 해결합니다. 기차·비행기 자동 배송은 지원 범위가 아닙니다.

필요 환경
- PC: Windows x64. 검증 환경은 Windows 11 x64입니다.
- 휴대폰: Township Android판, 게임 언어 English, USB 디버깅 허용,
  데이터 전송 가능한 USB 케이블과 정상 작동하는 ADB 연결이 필요합니다.
- 게임 화면: 원본 ADB 캡처 1544×720, 가로 화면(rotation=90), 주 디스플레이.
  마을 배치와 카메라 위치도 등록된 화면 조건에 맞아야 합니다.
  다른 해상도·배치는 실제 게임 캡처로 인식 자료를 추가 등록하고 검증해야 합니다.
- 실행 구성: Node.js 24.x, Python 3.12, .NET 8 Desktop Runtime x64,
  Android Platform Tools와 Python 인식 패키지를 별도 설치합니다.
- 로컬 AI: D1-3B 모델과 제공된 설치 절차의 llama.cpp/CUDA 런타임이 필요합니다.
  검증 GPU는 NVIDIA RTX 4070 SUPER 12GB입니다. 최소 GPU·RAM 사양은 미측정이며,
  CPU 전용·AMD·Intel GPU 환경은 이 배포 절차로 검증하지 않았습니다.
- 저장 공간: 초기 설치용 여유 공간 10GB 이상 권장. 모델·프로젝터는 약 3.73GB이며,
  런타임·패키지·작업 캡처 저장 공간이 추가로 필요합니다. 최초 설치에는 인터넷이 필요합니다.

배포 ZIP에는 실행 파일, 프로그램 소스, 인식 이미지, 설치 도구와 상세 안내가 포함됩니다.
게임 APK·계정, 개인 기기 설정, 이전 실행 상태, AI 모델과 외부 런타임은 포함하지 않습니다.
압축을 완전히 푼 뒤 readme.txt에 따라 환경을 구성하고 Start-ADB.cmd로 실행하세요.
새 설치는 일시정지 상태로 시작합니다. 유료 가속·TCash·쿠폰·딜러 구매는 사용하지 않습니다.
